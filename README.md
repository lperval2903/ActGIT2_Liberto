# ActGIT2

## Descripción
El proyecto ActGIT2 es una herramienta de control de versiones que permite a los desarrolladores gestionar y colaborar en proyectos de software de manera eficiente. Con ActGIT2, los usuarios pueden realizar un seguimiento de los cambios en el código fuente, fusionar ramas, resolver conflictos y mantener un historial completo de las modificaciones realizadas en el proyecto.
